# TCAD-NMOSFET-180NM-CHANNEL-2NM-OXIDE-
The repository contains the process simulation script, device simulation scripts, extracted electrical characteristics, and visualized device structure.
Project Overview
This project focuses on the process simulation, fabrication flow modelling, and electrical characterization of an NMOS transistor using Synopsys Sentaurus TCAD.

The device was constructed using Sentaurus Process (SProcess), followed by electrical simulations using Sentaurus Device (SDevice).
Tools Used
- Synopsys Sentaurus Process
- Synopsys Sentaurus Device
- Sentaurus Visual
- Command files and scripting for TCAD simulation
Project Workflow
1. Silicon substrate initialization and doping.
2. Gate oxide formation.
3. Polysilicon gate deposition and patterning.
4. Source/drain implantation and thermal diffusion.
5. Spacer formation and contact creation.
6. Final NMOS structure generation.
7. DC and AC electrical characterization.
Electrical Characterization
- ID–VG transfer characteristics
- ID–VD output characteristics
- Threshold voltage extraction
- ON-current and OFF-current extraction
- ON/OFF current ratio
- Capacitance characteristics (Cgg,Cgs,Cgd,Cds)
